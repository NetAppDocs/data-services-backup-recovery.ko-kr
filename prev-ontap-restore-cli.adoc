= ONTAP CLI를 사용하여 ONTAP 데이터를 복원합니다.
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
백업 및 복구 웹 UI를 사용하여 일부 ONTAP 데이터를 복원하지 못할 수 있습니다. 이는 시스템 등록을 해제한 후에도 백업을 유지했거나, 더 이상 존재하지 않는 관계를 통해 백업이 생성된 경우에 발생할 수 있습니다. 이러한 경우 ONTAP CLI를 사용하여 백업을 복원하십시오.

.시작하기 전에
* 타겟 클러스터의 ONTAP CLI에 액세스할 수 있는지, 그리고 복원할 백업 복사본이 무엇인지 알고 있는지 확인하십시오.
* 다른 ONTAP 클러스터로 복원하는 경우, 해당 클러스터는 이미 동일한 오브젝트 스토어에 액세스할 수 있어야 합니다. 필요한 경우 복원하기 전에 타겟 클러스터에서 오브젝트 스토어를 구성하십시오.
* 시스템 등록을 해제하기 전에 새 백업 관계가 생성된 경우, NetApp Backup and Recovery는 새 백업이 생성된 후 최대 1시간 동안 이전 스냅샷을 계속 표시할 수 있습니다. 이 새로 고침 시간 동안 이전 스냅샷에 대한 UI 기반 복원이 실패할 수 있습니다.


.단계
. NetApp Backup and Recovery 메뉴에서 *보고서*를 선택합니다.
. 백업 보고서를 다운로드하세요.
. 보고서에서 복원하려는 볼륨을 찾고 필요한 백업 복사본의 엔드포인트 항목을 찾으십시오:
+
** 이전 관계에서 생성된 오래된 백업의 경우 *엔드포인트 UUID 기록* 값을 사용하십시오.
** 현재 관계의 백업을 생성하려면 *엔드포인트 UUID* 값을 사용하십시오.
+
각 기록 항목은 다음 형식을 사용합니다 `<bucket_name>:<endpoint_uuid>`. 복원하려는 백업의 버킷 이름과 엔드포인트 UUID를 기록하십시오.



. ONTAP 클러스터 CLI에 연결하고 진단 모드로 진입합니다:
+
[source, shell]
----
set -privilege diagnostic
----
. 타겟 데이터 보호(DP) 볼륨을 생성합니다:
+
[source, shell]
----
volume create -vserver <vserver_name> -volume <volume_name> -aggregate <aggr_name> -size <size> -type DP
----
. 기록한 버킷 및 엔드포인트 UUID에 대해 사용 가능한 스냅샷 목록을 표시합니다:
+
[source, shell]
----
snapm object-store endpoint snapshot show -object-store-name <bucket_name> -endpoint-uuid <endpoint_uuid>
----
+

NOTE: 이 명령은 ONTAP이 해당 버킷 및 엔드포인트에 대해 추적하는 스냅샷만 나열합니다. 수동으로 다른 버킷으로 이동된 스냅샷은 나열하지 않습니다.

. 백업이 생성된 후 오브젝트 저장소 자격 증명이 변경된 경우, 계속 진행하기 전에 오브젝트 저장소 구성을 업데이트하십시오:
+
[source, shell]
----
snapmirror object-store config show -object-store-name <object_store_name>
snapmirror object-store config modify -object-store-name <object_store_name> -access-key <new_access_key> -secret-password <new_secret_password>
----
. 선택한 스냅샷을 오브젝트 스토리지에서 대상 DP 볼륨으로 복원합니다:
+
[source, shell]
----
snapmirror restore -destination-path <vserver>:<destination_volume> -source-path <bucket_name>:/objstore/<endpoint_uuid> -source-snapshot <snapshot_name> -source-endpoint-uuid <endpoint_uuid>
----
