NetApp Backup and Recovery가 워크로드 전반에 걸쳐 백업 및 복원 작업에 지원하는 소스 시스템, 2차 시스템 및 오브젝트 스토리지 대상을 검토하십시오.



[[supported-systems-for-backup-and-restore-operations]]
== 백업 및 복원 작업을 위한 지원 시스템

NetApp Backup and Recovery ONTAP 시스템과 퍼블릭 및 프라이빗 클라우드 공급업체를 지원합니다.



[[supported-regions]]
=== 지원되는 지역

NetApp Backup and Recovery 많은 Amazon Web Services, Microsoft Azure 및 Google Cloud 지역에서 Cloud Volumes ONTAP 통해 지원됩니다.

https://bluexp.netapp.com/cloud-volumes-global-regions["글로벌 지역 지도를 사용하여 자세히 알아보세요"^]



[[supported-backup-destinations]]
=== 지원되는 백업 대상

NetApp Backup and Recovery를 사용하면 다음 소스 시스템의 데이터를 퍼블릭 및 프라이빗 클라우드 공급자의 다음 2차 시스템 및 오브젝트 스토리지로 백업할 수 있습니다. 스냅샷은 소스 시스템에 상주합니다.


NOTE: 현재 Wasabi는 S3 호환 객체 스토리지 제공업체 중 유일하게 인증을 받은 업체입니다. 다른 S3 호환 제공업체는 아직 검증되지 않았습니다.

[[supported-restore-destinations]]
=== 지원되는 복원 대상

2차 시스템(복제된 볼륨) 또는 오브젝트 스토리지(백업 파일)에 있는 백업 파일, 가상 머신, 데이터베이스 또는 Kubernetes 리소스의 데이터를 다음 시스템으로 복원할 수 있습니다. 스냅샷은 소스 시스템에 상주하며 동일한 시스템으로만 복원할 수 있습니다.


NOTE: 현재 Wasabi는 S3 호환 객체 스토리지 제공업체 중 유일하게 인증을 받은 업체입니다. 다른 S3 호환 제공업체는 아직 검증되지 않았습니다.

| S3 호환 오브젝트 스토리지(ONTAP 볼륨만 해당) | 온프레미스 ONTAP 시스템 | 온프레미스 ONTAP 시스템 
|===
복원 시 다음 사항을 고려하십시오.

* Cloud Volumes ONTAP(복제)에서의 복원은 Cloud Volumes ONTAP으로만 수행할 수 있습니다. 하지만 AWS의 Cloud Volumes ONTAP은 Amazon FSx for NetApp ONTAP으로의 복원도 지원합니다.
* 온프레미스 ONTAP(복제)에서의 복원은 온프레미스 ONTAP으로만 수행할 수 있습니다.
* 퍼스트 파티 Amazon FSx for NetApp ONTAP 및 Google Cloud NetApp Volumes(복제)에서의 복원은 각각의 퍼스트 파티 시스템으로만 수행할 수 있습니다.
* Amazon S3에서 Amazon FSx for NetApp ONTAP으로의 복원은 다음 순서를 따라야 합니다: Amazon S3에서 Cloud Volumes ONTAP으로, 그런 다음 Cloud Volumes ONTAP에서 Amazon FSx for NetApp ONTAP으로.



NOTE: "온프레미스 ONTAP 시스템"에는 FAS, AFF 및 ONTAP Select 시스템이 포함됩니다.
