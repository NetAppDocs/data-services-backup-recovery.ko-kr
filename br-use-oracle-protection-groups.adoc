= NetApp Backup and Recovery를 사용하여 Oracle Database 워크로드용 보호 그룹을 생성하고 관리하세요
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Oracle 데이터베이스 리소스에 대한 백업 작업을 관리하기 위해 보호 그룹을 생성합니다. 보호 그룹은 데이터베이스 등 함께 보호하려는 리소스를 논리적으로 그룹화한 것입니다.

보호 그룹과 관련된 다음 작업을 수행할 수 있습니다.

* 보호 그룹을 만듭니다.
* 보호 세부 정보를 확인하세요.
* 지금 바로 보호 그룹을 백업하세요. link:br-use-oracle-backup.html["지금 바로 Oracle Database 워크로드를 백업하세요"]을 참조하십시오.
* 보호 그룹을 삭제합니다.




[[create-a-protection-group]]
== 보호 그룹 생성

보호하려는 Oracle 데이터베이스 리소스를 보호 그룹으로 묶으십시오.

*필수 NetApp Console 역할* 백업 및 복구 슈퍼 관리자 또는 백업 및 복구 백업 관리자 역할. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["모든 서비스에 대한 NetApp Console 액세스 역할에 대해 알아보세요."^].

.단계
. NetApp Backup and Recovery 메뉴에서 *인벤토리*를 선택합니다.
. 보호 세부 정보를 보려면 작업 부하를 선택하세요.
. 작업 아이콘을 선택하세요image:../media/icon-action.png["작업 옵션"] > *자세히 보기*.
. *보호 그룹* 탭을 선택하세요.
. *보호 그룹 만들기*를 선택합니다.
. 보호 그룹의 이름을 입력하세요.
. 보호 그룹에 포함할 데이터베이스를 선택하십시오.
+
대기 데이터베이스는 기본적으로 목록에 표시되지 않습니다. 목록을 보려면 *Data Guard 대기 데이터베이스 표시*를 선택하십시오. Oracle Data Guard 구성의 일부인 데이터베이스를 선택하면 NetApp Backup and Recovery도 동일한 구성에 있는 다른 데이터베이스를 추가합니다. 해당 데이터베이스가 검색되고 보호 가능하며 다른 보호 그룹에 속해 있지 않은 경우에만 추가됩니다.

. *다음*을 선택하세요.
. 보호 그룹에 적용할 *백업 정책*을 선택하십시오. 그룹에 Oracle Data Guard 데이터베이스가 포함된 경우 정책의 *Data Guard 설정*을 사용하여 백업할 데이터베이스를 선택하십시오. link:br-use-policies-oracle-create.html["Oracle Database 백업 정책 생성 및 관리"]을(를) 참조하십시오.
+
정책을 만들려면 *새 정책 만들기*를 선택하고 메시지에 따라 정책을 만드세요.  보다link:br-use-policies-create.html["정책 생성"] 자세한 내용은.

. *다음*을 선택하세요.
. 구성을 검토하세요.
. 보호 그룹을 생성하려면 *생성*을 선택하세요.



NOTE: 보호 그룹을 생성한 후 대기 호스트를 추가하는 경우, 보호 그룹을 편집하고 저장하십시오. NetApp Backup and Recovery는 대기 호스트를 자동으로 추가합니다. 대기 호스트에서는 대기 데이터베이스만 그룹에 추가하십시오. 해당 호스트에서 다른 백업 유형이 필요한 다른 데이터베이스가 있으면 해당 호스트의 백업이 실패합니다.



[[delete-a-protection-group]]
== 보호 그룹 삭제

보호 그룹을 삭제하면 해당 보호 그룹과 관련된 모든 백업 일정이 제거됩니다. 더 이상 필요하지 않은 경우 보호 그룹을 삭제할 수 있습니다.

.단계
. NetApp Backup and Recovery 메뉴에서 *인벤토리*를 선택합니다.
. 보호 세부 정보를 보려면 작업 부하를 선택하세요.
. 작업 아이콘을 선택하세요image:../media/icon-action.png["작업 옵션"] > *자세히 보기*.
. *보호 그룹* 탭을 선택하세요.
. 삭제할 보호 그룹을 선택하세요.
. 작업 아이콘을 선택하세요image:../media/icon-action.png["작업 옵션"] > *보호 기능을 제거합니다*.
. 연관된 백업을 삭제한다는 확인 메시지를 검토하고 삭제를 확인하세요.
