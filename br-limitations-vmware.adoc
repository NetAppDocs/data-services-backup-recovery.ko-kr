= NetApp Backup and Recovery에서 VMware 워크로드에 대한 알려진 제한 사항
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup and Recovery를 사용하여 VMware 워크로드를 처리하기 전에 다음 제한 사항을 검토하십시오.

NetApp Backup and Recovery는 VMware 워크로드에 대해 다음과 같은 작업을 지원하지 않습니다.

* NetApp Console 로컬 배포용 Backup and Recovery 미리 보기 릴리스에서는 오브젝트 스토리지로의 백업이 ONTAP S3 및 StorageGRID 대상에 대해서만 지원됩니다. 이 미리 보기 릴리스에서는 백업 아카이빙이 지원되지 않습니다.
* vVol 지원
* 이메일 통합
* 역할 기반 액세스 제어(RBAC) 지원
