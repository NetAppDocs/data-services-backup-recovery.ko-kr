= NetApp Backup and Recovery 사용하여 VMware 워크로드 백업
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
온프레미스 ONTAP 시스템의 VMware VM 및 데이터스토어를 Amazon Web Services, Azure NetApp Files 또는 StorageGRID에 백업하여 데이터를 보호하십시오. 백업은 자동으로 생성되어 공용 또는 프라이빗 클라우드 계정의 오브젝트 스토어에 저장됩니다.

* 워크로드를 예약된 시간에 백업하려면 백업 및 복원 작업을 관리하는 정책을 생성하십시오. link:br-use-policies-create.html["보호 정책 생성"]를 참조하십시오.
* 리소스 집합에 대한 백업 및 복원 작업을 관리하기 위해 보호 그룹을 생성합니다. 자세한 내용은 link:br-use-vmware-protection-groups.html["보호 그룹 생성 및 관리"]를 참조하십시오.
* 온디맨드 백업을 생성하여 지금 바로 워크로드를 백업하십시오.




[[back-up-workloads-now-with-an-on-demand-backup]]
== 지금 온디맨드 백업으로 워크로드를 백업하세요

즉시 주문형 백업을 생성합니다.  시스템을 변경하려는 경우, 변경을 시작하기 전에 백업이 있는지 확인하려면 주문형 백업을 실행하는 것이 좋습니다.

*필수 NetApp Console 역할* 백업 및 복구 슈퍼 관리자, 백업 및 복구 백업 관리자, 백업 및 복구 클론 관리자 또는 백업 및 복구 뷰어 역할. Cloud Volumes ONTAP 클러스터에 저장된 데이터를 보호하는 경우 Cloud Volumes ONTAP 관리자 역할도 필요합니다. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["모든 서비스에 대한 NetApp Console 액세스 역할에 대해 알아보세요."^].

.단계
. NetApp Backup and Recovery 메뉴에서 *인벤토리*를 선택합니다.
. VMware 워크로드를 선택하십시오.
. 작업 아이콘을 선택하세요image:../media/icon-action.png["작업 옵션"] > *자세히 보기*.
. *Protection Groups*, *Datastores*, *Virtual machines* 또는 *Tags* 메뉴 제목을 선택하십시오.
. 백업할 보호 그룹, 데이터 저장소, 가상 머신 또는 태그가 지정된 리소스를 선택하십시오.
. 작업 아이콘을 선택하세요image:../media/icon-action.png["작업 옵션"] > *지금 뒤로 물러나세요*.
+

NOTE: 백업에 적용되는 정책은 보호 그룹, 데이터 저장소, 가상 머신 또는 태그가 지정된 리소스에 할당된 정책과 동일합니다.

. 일정 단계를 선택하세요.
. *지금 백업*을 선택하세요.




[[delete-backups]]
== 백업 삭제

스토리지 공간을 확보하거나 데이터 보존 요건을 충족하기 위해 더 이상 필요하지 않은 로컬 백업을 삭제할 수 있습니다.

.단계
. NetApp Backup and Recovery에 로그인하고 홈 화면에서 VMware 워크로드 타일을 선택합니다.
+
VMware 인벤토리 페이지가 나타납니다.

. *가상 머신* 항목을 선택합니다.
. 가상 머신 목록에서 가상 머신을 선택하고 작업 아이콘 image:../media/icon-action.png["작업 옵션"] > *보호 세부 정보 보기*를 선택합니다.
. 관련 스냅샷을 표시할 기간을 선택합니다.
. 스냅샷을 하나 이상 삭제합니다.
+
[role="tabbed-block"]
====
.스냅샷 하나 삭제
--
.. 목록에서 삭제할 스냅샷을 선택하고 작업 아이콘 image:../media/icon-action.png["작업 옵션"] > *로컬 스냅샷 삭제*를 선택합니다.


--
.여러 스냅샷 삭제
--
.. 삭제하려는 각 스냅샷 왼쪽에 있는 확인란을 선택합니다.
.. *선택한 항목 삭제*를 선택합니다.


--
