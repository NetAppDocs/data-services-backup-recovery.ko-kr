= NetApp Backup and Recovery를 사용한 Kubernetes 보호 워크플로
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup and Recovery를 사용하여 단일 인터페이스에서 Kubernetes 클러스터와 애플리케이션을 검색, 관리 및 보호하십시오.

다음 다이어그램은 Kubernetes 백업 및 복구의 구성 요소와 기본 아키텍처, 그리고 데이터 복사본을 여러 위치에 저장하는 방법을 보여줍니다.

image:../media/backup-recovery-architecture-diagram.png["Kubernetes 워크로드에 대한 백업 및 복구 아키텍처 다이어그램"]

NetApp Backup and Recovery Kubernetes 워크로드 관리에 다음과 같은 이점을 제공합니다.

* 컨테이너 및 가상 머신을 포함하여 여러 Kubernetes 클러스터에 걸쳐 애플리케이션을 보호하기 위한 단일 제어 평면입니다.
* NetApp SnapMirror와의 기본 통합을 통해 백업 및 복구 워크플로우를 위한 스토리지 오프로드가 가능합니다.
* Kubernetes 애플리케이션에 대한 증분적 영구 백업은 복구 지점 목표(RPO)와 복구 시간 목표(RTO)를 낮추는 데 도움이 됩니다.
