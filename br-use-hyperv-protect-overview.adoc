= NetApp Backup and Recovery로 Hyper-V 워크로드를 보호합니다
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup and Recovery를 사용하여 CIFS 공유에 호스팅된 독립 실행형 Hyper-V VM, 장애 조치 클러스터 인스턴스 및 SCVMM 프로비저닝 VM을 백업하고 복원합니다.

Hyper-V 워크로드를 Amazon S3 또는 StorageGRID에 백업하고 온프레미스 Hyper-V 호스트로 복원할 수 있습니다.

NetApp Backup and Recovery를 사용하여 3-2-1 보호 전략을 구현하십시오. 원본 데이터의 복사본을 서로 다른 두 개의 스토리지 시스템에 세 개, 클라우드에 한 개를 저장하는 방식입니다. 3-2-1 접근 방식의 이점은 다음과 같습니다.

* 여러 개의 데이터 사본을 보관하여 내부 및 외부 사이버 보안 위협으로부터 보호합니다.
* 여러 미디어 유형을 사용하면 하나의 미디어 유형에 물리적 또는 논리적 장애가 발생하더라도 장애 복구 기능을 유지할 수 있습니다.
* 현장 복사본을 사용하면 데이터를 신속하게 복원할 수 있으며, 현장 복사본이 손상된 경우 오프사이트 복사본을 사용할 수 있습니다.


Hyper-V 호스트를 추가하고 리소스를 검색하면 NetApp Backup and Recovery는 가상 머신을 관리하고 보호하기 위해 각 Hyper-V 호스트에 NetApp Hyper-V 플러그인과 NetApp SnapCenter Windows FileSystem 플러그인을 설치합니다.
